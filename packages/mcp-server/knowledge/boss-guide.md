# Boss 指南（STS2）

## 适用范围

- 本文覆盖当前 `Early Access` 版本可确认的 `12` 个战斗 Boss。
- 按 2026-03-20 检索到的公开攻略与本地 MCP 实战信息整理。
- 当前可确认的区域是：
- `Act 1 Overgrowth` 3 个 Boss
- `Act 1 Underdock` 3 个 Boss
- `Act 2 Hive` 3 个 Boss
- `Act 3 Glory` 3 个 Boss

## 重要说明

- 外部资料对荣耀层实验体的编号存在冲突。
- `GameSpot` 与本地 MCP 实战都出现过 `Test Subject #C8`。
- `All Things How` 等部分攻略写作 `Test Subject #C10`。
- 目前能确认的是机制一致：三阶段 `100 -> 200 -> 300 HP`，一阶段技能触发加力，二阶段未格挡伤害塞伤口，三阶段隔回合无实体。
- 本文正文统一写作 `实验体 C 系列（本地观测为 #C8）`，避免被外部攻略的编号差异误导。

## 通用进 Boss 检查

- 我是否已经知道这一层 Boss 是谁。
- 我这套牌能不能处理单回合 `30+` 伤害。
- 我有没有明确的单体终结手段。
- 我有没有至少一种处理多目标的办法。
- 我有没有过牌或回费，不会关键回合只能看着手牌发呆。
- 我是否愿意在 Boss 战里主动交药水。

## Act 1 Overgrowth

### Vantom

核心机制：

- 开局有多层 `Slippery`，前几次命中几乎都只能打 `1` 点。
- 进入固定循环：轻击、连击、重击加塞 `Wound`、再加力量后重置循环。
- 重击回合伤害会明显跳升，是这一战最危险的节点。

构筑检查：

- 多段攻击优先级很高。
- 低费攻击、免费攻击、连打牌明显更好。
- 能清掉或消耗 `Wound` 的牌会降低后续坏抽。

打法建议：

- 前两回合可以接受少量掉血，换取更快拆完 `Slippery`。
- 第三回合的高伤和 `Wound` 才是真正要重点防的地方。
- 如果你主要靠单段大数字输出，这个 Boss 会比面板血量看起来更难打。

### Ceremonial Beast

核心机制：

- 第一阶段带 `Plow`，会一边攻击一边叠力量。
- 当血量降到 `150` 或以下时会眩晕，并清掉阶段一累计的力量。
- 进入第二阶段后会交替使用攻击与 `Ringing`，让你每回合只能打 `1` 张牌。

构筑检查：

- 不能只会慢慢磨。
- 需要在进 `150` 阈值前，准备一轮高质量输出。
- 单卡质量越高，这战后半越轻松，因为 `Ringing` 会惩罚靠连锁出牌的牌组。

打法建议：

- 最好把它压到接近 `150` 时，再准备一轮爆发把它送进眩晕窗口。
- 眩晕回合和刚进二阶段的那一两回合，是最值得把资源砸出去的时机。
- 如果让二阶段拖太久，`只能出一张牌` 会把很多构筑直接锁死。

### Kin Priest / Kin Shaman + 2 Followers

核心机制：

- Boss 是多单位战。
- 两个追随者会交替加力量和攻击。
- 后排神官会打伤害、上 `Frail` / `Weak`，并逐渐给自己叠力量。
- 击杀神官时，小弟会直接逃跑。

构筑检查：

- 有 AOE 时，可以先削行动体数量。
- 有强单点爆发时，可以考虑直接冲后排首领。
- 如果你两边都不强，这战会因为总行动数太多而很难受。

打法建议：

- 单体爆发构筑：优先评估能否在承伤可控前提下直接秒后排。
- 平推或 AOE 构筑：通常先清小弟更稳，先减少总伤害和总 buff。
- 关键不是固定答案，而是根据你牌组到底擅长单点还是擅长铺开来选击杀顺序。

## Act 1 Underdock

### Lagavulin Matriarch

核心机制：

- 开局沉睡并带 `12` 层护甲/副甲。
- 有一段相对安全的启动窗口。
- 苏醒后会进入攻击、多段攻击、攻击加抬甲、再到削你 `Strength` / `Dexterity` 并给自己加力量的循环。
- 拖得越久，你越弱，它越强。

构筑检查：

- 前几回合要能有效启动。
- 不依赖 `Strength` 的输出体系更舒服，比如毒、Doom、Orb、召唤物、稳定成长伤害。
- 如果你的输出和防御都强依赖力量/敏捷，这战会被它天然克制。

打法建议：

- 沉睡阶段优先上能力、上成长、整理循环。
- 真正开打后不要拖，越拖属性越差。
- 如果你是慢热牌组，也要尽量保证在它开始属性压制之前进入有效输出。

### Soul Fysh

核心机制：

- 往你的牌堆与弃牌堆里塞 `Beckon`。
- `Beckon` 如果留在手里回合结束，会直接失去 `6 HP`，不是普通伤害，格挡挡不住。
- 战斗中会加 `Intangible`、上 `Vulnerable`、继续塞更多 `Beckon`。

构筑检查：

- 高费笨重构筑会打得更难，因为费用会被 `Beckon` 挤占。
- 能消耗、转化、弃掉状态牌的牌会很好用。
- 过牌和回费越强，越容易稳住这战的节奏。

打法建议：

- `Beckon` 进手后，默认优先处理，不要拿它和普通攻击权衡。
- `Intangible` 回合不要硬砸大伤害，更多做防守、铺 Buff、整理下回合。
- 这战真正输法通常不是被一拳打死，而是被 `Beckon` 和易伤慢慢拖死。

### Waterfall Giant

核心机制：

- 本体会逐回合叠 `Steam Eruption`。
- 这个层数决定了它被打到 `0 HP` 以后最终自爆的伤害。
- 它死后不会立刻结束，而是会有一个短暂的结算窗口，之后爆炸。
- 战斗越长，最后的爆炸越危险。

构筑检查：

- 这是典型速杀检查。
- 需要高效单体输出。
- 弱化、格挡药水、保留防御牌都很有价值，因为最后一下经常才是真杀招。

打法建议：

- 不要只看“我快打死它了”，要看“打死后那回合我能不能活”。
- 能快杀就快杀，别让 `Steam Eruption` 无意义叠高。
- 终结回合前，尽量把最强防御资源留给它。

## Act 2 Hive

### The Insatiable

核心机制：

- 第一回合开 `Sandpit`，开始倒计时。
- 倒计时归零就是直接死亡，不是普通承伤。
- 它会往你牌组塞 `Frantic Escape`，打出后可以把倒计时往后延。
- 但这些牌的费用会随着使用次数逐渐上升。

构筑检查：

- 这就是纯粹的 DPS 与资源管理检查。
- 没有像样输出的套牌大概率直接过不了。
- 有过牌但没回费、或有回费但没输出，都会非常难受。

打法建议：

- 不要把所有费用都花在输出上，要预留打 `Frantic Escape` 的空间。
- 如果你的套牌本来就偏慢，这战必须靠药水和爆发资源抢节奏。
- 关键不是“能不能活住”，而是“能不能在倒计时和承伤同时存在的情况下尽快把它打死”。

### Knowledge Demon

核心机制：

- 每次它上 debuff，你都要二选一吃负面效果。
- 已知负面包括：
- `Disintegration`：回合结束掉血，而且会越来越痛。
- `Mind Rot`：每回合少抽牌。
- `Sloth`：每回合最多出 `3` 张牌。
- `Waste Away`：每回合少获得主资源。
- 除此之外它还会打伤害、加压、甚至回血。

构筑检查：

- 这战最怕“什么都想做一点”的杂牌组。
- 真正强的是聚焦型牌组：一件事做得非常强，哪怕被限制也还能工作。
- 毒、Doom、稳定成长、强被动收益通常都不错。

打法建议：

- 这战要更积极，而不是更保守，因为它会越拖越强。
- 选 debuff 时，优先吃你当前构筑最能承受的那一个，不要机械选固定答案。
- 对依赖大量过牌的牌组，少抽牌会很伤。
- 对依赖多出牌回合的牌组，限 `3` 张牌会很伤。
- 对依赖高费回合的牌组，减能量会很伤。

### Kaiser Crab

核心机制：

- 实际是双目标 Boss：`Crusher` 和 `Rocket` 两只钳子。
- 双方都有后方加伤或高压攻击能力。
- 一只死后，另一只会临时拿到 `+5 Strength` 和 `99 Block`，但只持续那一轮，不是永久锁死。
- `Rocket` 的爆发更高，但有些大招后下一回合会出现喘息窗口。
- `Crusher` 更肉，也更擅长抬防。

构筑检查：

- 单体构筑也能打，但会更看击杀顺序。
- 双目标伤害、溅射伤害、伪 AOE 都能提高容错。
- 如果你完全没有快速处理一个高威胁目标的能力，这战会很磨。

打法建议：

- 默认先处理 `Rocket`，因为它更容易直接把你压死。
- `Crusher` 更像拖时间和抬甲的那一端。
- 不必执着于同回合一起杀，因为另一只的爆发增益不是永久的。

## Act 3 Glory

### Doormaker

核心机制：

- 开局你看到的是 `Door`，不是本体。
- 先打爆门，本体才会出现。
- 本体出场时会有一个眩晕窗口，这是最好的输出时机。
- 随后本体会重击、加力量、撤回门后，再次重置循环。
- 每循环一次，新门的血量还会继续增加。

构筑检查：

- 这是节奏和爆发窗口检查，不是纯粹的长战。
- 你必须能在有限窗口里打出足够高的有效伤害。
- 如果只能慢慢磨门、磨本体，这战会越循环越不可收拾。

打法建议：

- 打门阶段就要尽量快，不能把资源都省着。
- 本体眩晕那一回合是最该交大牌、药水、复制、爆发的时机。
- 这战经常不是死于本体，而是死于越来越厚、越来越痛的门。

### The Queen + Torch Head Amalgam

核心机制：

- 女王会给你的牌挂 `Chains of Binding`，让你每回合前几张牌带 `Bound`，限制出牌自由。
- 她还会给你挂极其夸张的超长 `Frail` / `Vulnerable` / `Weak`。
- `Torch Head Amalgam` 才是更直接的伤害源，能多段输出。
- 火炬头会在女王死后逃跑，但反过来不成立。

构筑检查：

- 这战既看抗 debuff，也看先手处理主伤害目标的能力。
- 如果你太依赖精确连招，`Bound` 会严重破坏回合结构。
- 稳定单卡质量和高效点杀在这战会比花哨连锁更值钱。

打法建议：

- 默认先杀 `Torch Head Amalgam`，先把最直接的承伤源拿掉。
- 对大多数牌组来说，忽视火炬头直接打女王都不现实。
- 如果你的套牌真有极端爆发能直接穿掉女王，那是例外，不是常规解。

### 实验体 C 系列（本地观测为 #C8）

核心机制：

- 总共三阶段，基础血量依次是 `100 -> 200 -> 300`(会随进阶难度提升)。
- 一阶段会因为你打 `Skill` 而加力量，同时施加易伤。
- 二阶段更强调未格挡伤害惩罚，会塞 `Wound`。
- 三阶段会出现 `Intangible`，通常是隔回合生效，并加入 `Burn` 压力。

构筑检查：

- 这是最标准的耐久 Boss 之一。
- 你既要有伤害，也要有稳定格挡，还要能跨阶段保住资源。
- 纯爆发但没防御、纯防御但没成长，这两种构筑都很容易在这里被拖死。

打法建议：

- 一阶段少打无必要的 `Skill`，避免白送它力量。
- 二阶段尽量做到满挡，不然 `Wound` 会快速把牌组搅烂。
- 三阶段只在非 `Intangible` 回合交关键伤害，`Intangible` 回合优先叠甲、过牌、铺 Buff。
- 本地 MCP 实战里，最终杀招是第三阶段的高额单次攻击，因此一定要为后段爆发回合留出防御资源。

## 结尾建议

- 看到 Boss 图标后，拿牌、删牌、升级、药水保留都要围绕这个 Boss 调整。
- 第一幕 Boss 更多是在检查你有没有补齐底层功能。
- 第二幕 Boss 开始检查你有没有聚焦成型。
- 第三幕 Boss 则是检查你的套牌是不是既有赢法，也有容错。
- 如果一个 Boss 总把你打死，不要先怪数值，先看构筑到底缺的是输出、格挡、过牌、回费还是阶段预案。
