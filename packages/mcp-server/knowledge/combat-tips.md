# 战斗决策（STS2）

## 每回合先做三件事

1. 看敌人意图和总伤害。
2. 算自己这回合的安全线。
3. 再决定是抢节奏、保命，还是铺成长。

不要一上来就按手牌强度从大到小乱打。很多输法都来自“先把爽牌打了，再发现格挡不够”。

## 安全线思维

- 当前回合不是只看“能不能活”，而是看“活下来之后，下回合会不会彻底崩盘”。
- 如果你为了多打一点伤害，把自己留在一个下回合无法承受的血线，那通常不是赚。
- 遇到未知敌人或后期 Boss 时，对单回合爆发的预留要更保守。

## 出牌顺序

### 先打信息牌，再打决定牌

- 抽牌、检索、生成资源、生成临时牌，通常应该先打。
- 这样能先看到完整手牌，再决定本回合是防守线还是爆发线。
- 但前提是这些牌不会让你失去关键资源或导致爆牌。

### 先上 debuff，再上输出

- 能减少敌方伤害的 debuff，往往比多打一张普通攻击更值。
- 能提高己方伤害的 debuff 或易伤效果，也应在主要攻击前上。

### 0 费牌不是必须立刻打完

- “0 费就应该全打掉”是常见误区。
- 如果 0 费牌会占手牌上限、打乱保留、改变弃牌、触发危险重排，应该先判断再打。
- 0 费牌只有在真正提升本回合收益时才是免费收益。

## 什么时候该进攻，什么时候该防守

优先进攻：

- 本回合能击杀高威胁目标。
- 能明显削减对方下回合输出。
- 当前血量和防御足以覆盖剩余伤害。

优先防守：

- 本回合无法完成关键击杀。
- 你正面对高额攻击或高概率坏抽。
- 这是敌人的爆发回合，或者你需要为下回合大回合做准备。

## 多目标战斗

- 优先级通常是：危险 debuffer > 高成长怪 > 召唤核心 > 普通输出怪。
- 如果你没有真正的 AOE，就要学会“用点杀制造人数优势”。
- 不要因为贪总伤害而把多个敌人都打残。能少一个行动体，收益往往比多打几点伤害更高。

## Boss 战

- Boss 战的关键不是“每回合都打满”，而是识别对方的关键回合。
- 需要提前准备的问题：
- 哪回合最痛？
- 哪个阶段切换后最危险？
- 我需要把药水留到哪一回合？
- 我的 Buff 是应该提前铺，还是等安全回合再铺？

## 药水使用

- 药水不是收藏品。能省掉一轮掉血、抢下一只威胁怪、顶过 Boss 大招时，就该用。
- 进攻药水主要用于抢节奏和拿击杀。
- 防御药水主要用于覆盖坏抽和大招回合。
- 一旦药水效果和文字存在偏差，立刻重新读取状态，不要按印象继续操作。

## 实战检查表

回合结束前，至少确认这些问题：

- 本回合总 incoming damage 是多少？
- 有没有必须处理的高威胁单位？
- 关键牌已经打出，还是应该保留到下一回合？
- 过牌和回费有没有被浪费？
- 药水是否值得现在交？

## 常见错误

- 明明该挡伤，却为了多打一点面板伤害把自己送进危险血线。
- 看到抽牌就先打，结果把本来要保留或弃掉的节奏全部打乱。
- 多目标战里均摊伤害，导致敌人一个都没死。
- Boss 战没有预留药水和爆发，关键回合只能硬吃。
